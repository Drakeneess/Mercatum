# Mercatum

Prototipo online de exploración hexagonal y supervivencia en un mercado paranormal persistente.

Este repositorio contendrá un monorepo con `apps/web` (Next.js), `apps/server` (Node.js/WebSocket) y `packages/shared` (reglas comunes).

> Estado: prototipo técnico. Sin autenticación, persistencia de personajes ni permadeath todavía.
